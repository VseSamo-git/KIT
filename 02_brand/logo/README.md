## Что нужно залить

От Андрея — три файла в эту папку:

1. **`kit-logo.svg`** — полный векторный логотип (хвост + КИТ + декор + tagline).
2. **`kit-mark.svg`** — только знак-хвост, без текста (для фавикона и stories-стикеров).
3. **`kit-logo.png`** — full-size PNG на прозрачном фоне, минимум 2000×2000.

После заливки — пересоберу `02_brand/BRANDBOOK_VISUAL.html` и презентации с настоящим логотипом вместо SVG-заглушки.

## Канонический локап

Согласно референсу, который прислала Оля:

```
       ╭───╮ ╭───╮
       │   │ │   │     ← знак: хвост кита (две монолинейные дуги + волна)
        ╲ ╱
         ▽

         К И Т         ← вордмарк (sans-serif, прописные)
        ─────
         декор         ← подпись (script italic, тонкая)

   ДЕКОР НА МЕРОПРИЯТИЯ ← тэглайн (uppercase tracked)
```

## Шрифты, которыми приближаем до момента получения оригинала

- **Знак:** `kit-mark.svg` в этой папке.
- **КИТ:** Space Grotesk Light 300, letter-spacing 0.15em.
- **«декор»:** Caveat Regular (Google Fonts) — приближённый аналог рукописного начертания.
- **ДЕКОР НА МЕРОПРИЯТИЯ:** Space Grotesk Regular 400, letter-spacing 0.25em, uppercase.
