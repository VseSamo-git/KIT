# Как обновить соцсети КИТ — инструкция для Оли

> Привет, Оля! 🤍
> Это пошаговая инструкция, как поменять оформление всех твоих соцсетей под новый бренд КИТ. Ничего сложного — просто следуй по списку. Все картинки и тексты уже готовы, они в папке `02_brand/assets_export/` в нашем гитхабе.
>
> Если что-то непонятно — пиши Андрею, разберёмся.

---

## С чего начать

1. **Открой репозиторий на GitHub** в браузере: ссылку даст Андрей.
2. **Зайди в папку** `02_brand/assets_export/` — там 8 подпапок по числу соцсетей.
3. **Каждую папку нужно скачать.** В GitHub нажимай на файл → справа сверху кнопка `Download` (стрелка вниз). Скачивай по одной картинке. Для текста (`.txt`) можно просто открыть и скопировать.
4. **Меняй соцсети по очереди.** Проще делать одну за раз, не прыгать.

## Порядок обновления (приоритет от важной к менее важной)

### 1. Instagram — главная площадка, начни отсюда

Файлы из `instagram/`:
- `avatar.png` — новая аватарка
- `bio.txt` — новый текст профиля
- `welcome_post.txt` — текст первого поста после ребрендинга
- `highlights/01-05_*.png` — обложки highlights (5 штук)
- `highlights_titles.txt` — какие названия дать каждой highlights

**Шаги:**
1. Зайди в Instagram → редактировать профиль.
2. Заменить аватар → `avatar.png`.
3. В поле «О себе» вставить текст из `bio.txt`. Если не вмещается — сократи последнюю строку.
4. **Залить 5 highlights:** пройди в свой профиль, нажми «+» под bio, создай 5 highlights с названиями из `highlights_titles.txt`. Для каждого выбери обложку из папки `highlights/`.
5. **Опубликовать пост-якорь** «Мы обновились» — текст в `welcome_post.txt`. Поставь как первое фото в карусели — `instagram/avatar.png`. Прикрепи ещё 4–5 лучших фото своих работ.
6. **Закрепить этот пост** наверху профиля (три точки → «Закрепить»).

⏱ Время: 30–40 минут.

### 2. Telegram-канал

Файлы из `telegram/`:
- `avatar.png` — новая аватарка канала
- `description.txt` — описание канала
- `welcome_post.txt` — короткий пост «Мы обновились»

**Шаги:**
1. Открой Telegram-канал → нажми на название → редактировать.
2. Заменить фото канала → `avatar.png`.
3. Описание → текст из `description.txt`. (Замени `@your_handle` на свой ник для связи.)
4. Опубликовать пост из `welcome_post.txt`, прикрепить тот же `avatar.png` (TG автоматически сожмёт).
5. Закрепить пост.

⏱ Время: 10 минут.

### 3. VK — нужно ещё переименовать

Файлы из `vk/`:
- `avatar.png` — аватар группы
- `cover.png` — обложка для десктопа
- `cover_mobile.png` — обложка для мобильного
- `description.txt` — описание группы
- `group_setup.txt` — что поменять в настройках (название, адрес)
- `welcome_post.txt` — пост-якорь

**Шаги:**
1. Управление сообществом → Настройки.
2. Поменять **название** на «КИТ · Декор на мероприятия» (см. `group_setup.txt`).
3. Поменять **короткое имя** на `kit_decor_spb` (адрес vk.com/kit_decor_spb).
4. Поменять **тематику** на «Декоратор / флорист».
5. Залить главное фото → `avatar.png`.
6. Залить обложку:
   - **Десктоп**: `cover.png` (1920×768)
   - **Мобильную**: `cover_mobile.png` (1196×400) — отдельно загружается в настройках обложек.
7. Описание → текст из `description.txt`.
8. Опубликовать пост из `welcome_post.txt` → закрепить.

⏱ Время: 30 минут.

### 5. YouTube — активный канал

Файлы из `youtube/`:
- `avatar.png` — аватар канала
- `channel_art.png` — баннер канала
- `watermark.png` — водяной знак для видео (с прозрачным фоном)
- `description.txt` — описание канала

**Шаги:**

3. **Раздел «Сведения»**:
   - Описание → `description.txt`
4. Сними/смонтируй первое видео по сценарию из `welcome_video_idea.txt` — это можно через 1–2 недели, не срочно.

⏱ Время: 20 минут на оформление, видео отдельно.

### 6. Pinterest — активная площадка

Файлы из `pinterest/`:

6. Обложка `cover.png` — на Pinterest нет «классической» обложки, но картинку можно использовать как первый pin или как cover главной доски.

⏱ Время: 30–40 минут (вместе с заливкой первых пинов).

## Современные правила соцсетей (что важно в 2026)

### 🔑 Главное: единое лицо везде

Когда человек переходит из IG в TG, потом из TG в VK — он должен видеть одну и ту же студию. Один логотип. Одна обложка. Один тон в описании. Это сильно повышает доверие. Поэтому мы и делаем все шапки одинаковыми.

### 📱 Сторис каждый день

Stories — не «по настроению», а каждый рабочий день. Хотя бы 2–3 кадра. Это держит охват профиля живым (алгоритм видит активность). Темы — простые: что варишь утром, как едешь на объект, какие цветы привезли.

### 💬 Отвечать на DM в первый час

Алгоритмы Instagram и VK поднимают тех, кто быстро отвечает в личке. Если кто-то написал «сколько стоит» — постарайся ответить в течение часа в рабочее время. Один день молчания = минус 30% к охвату следующего поста.

### 🚫 Не ставить много хэштегов в постах

В 2026 хэштеги работают слабо. Достаточно 4–6 в конце поста. Главное — чтобы хэштеги были **локальные** (`#свадьбаСПб`, `#декорСПб`) и **тематические** (`#свадебныйдекор`, `#флористикаСПб`). Никаких «#любовь #счастье #свадьба #wedding» — это шум.

### 🎵 Reels — три в неделю, обязательно

Это главный канал органического охвата сейчас. Рилсы дают тебе подписчиков, посты — нет. Форматы, которые работают:
- **Тайм-лапс монтажа** (15–30 сек): пустой зал → 6 часов работы → готовая площадка.
- **До/после**: 5 секунд «было» + 5 секунд «стало».
- **Ольга и Андрей в кадре**: коротко, без сценария — «вот что мы сегодня сделали».

Музыку выбирай **из трендов недели** (Reels подсказывает, что популярно). Не свою любимую.

### 📅 Лучшее время постить

Для свадебной аудитории СПб (девушки 25–35):
- **Утро**: 8:00–9:30 (по дороге на работу)
- **Обед**: 13:00–14:00
- **Вечер**: 18:30–20:00

Reels лучше ставить **вечером в 18:00–19:00** — пиковое время скролла.

### 🤍 Один эмодзи в конце поста — фирменно

Маленькое белое сердечко 🤍 в конце эмоциональных постов — это уже наш узнаваемый знак. Никаких 😍🥰💕 (слишком сладко) или 🔥❗💥 (слишком кричаще).

### 📸 Фото — только свои, обработанные одним пресетом

Никаких стоковых картинок никогда. Все фото должны быть в одной цветовой температуре (тёплой), мягкий контраст. Если есть пресет в Lightroom — используй его всегда. Это создаёт визуальное единство ленты.

### 🚫 Что мы никогда не делаем

- Не пишем «уникальный декор», «команда профессионалов», «премиум-качество» — это пустые слова, у нас в брендбуке прямо запрещено.
- Не клянчим лайки и подписки в постах.
- Не используем CAPS LOCK через две строки и больше двух восклицательных знаков подряд.
- Не выкладываем чужие работы под видом своих.
- Не игнорируем комментарии, даже если они «вроде ни о чём». Каждый ответ = +1 к охвату.

### 🤖 Через неделю-две запустим Idea Bot

Андрей сейчас собирает Telegram-бота `@kit_ideas_bot`. Когда он будет готов — ты сможешь просто записать голосовое сообщение со своей идеей («сегодня монтировали в Ботаническом саду»), и через 3 минуты получить готовые черновики постов в IG/TG/VK. Тебе останется только нажать «опубликовать» или «правки».

Пока этого нет — пиши идеи в обычные заметки, потом разберём вместе.

## Что делать, если что-то не получается

1. **Картинка не подошла по размеру** — позвони Андрею, перерендерим за минуту.
2. **VK не даёт переименовать группу** — это ограничение по числу подписчиков. Скажи Андрею, посмотрим обходные пути.
3. **YouTube не принимает channel art** — попробуй другой браузер, иногда YouTube глючит. Если совсем не идёт — pull request на ресайз сделаем.
4. **Pinterest не пускает на ваш email** — проверь spam, мог уйти код подтверждения.
