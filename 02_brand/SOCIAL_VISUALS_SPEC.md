# Social Visuals Spec · что собираем для каждой платформы

> Спецификация ассетов под все 7 платформ. Все размеры — пиксели.
> Все ассеты строятся по `04_BRAND_BOOK.md`: Editorial Noir, Tenor Sans + Marck Script + Space Grotesk, чёрный фон.
> Исходный логотип: `02_brand/logo/kit-logo.jpg`.

---

## Общие принципы для всех ассетов

**Аватар** (везде квадрат):
- Фон Noir `#080808`.
- Только **знак-хвост** Paper (без вордмарка) — он должен читаться при размере 32×32 пикселя.
- Охранная зона 12% от ширины со всех сторон.

**Обложка/Cover** (горизонтальная):
- Фон Noir.
- В центре или слева — полный логотип-локап (хвост + КИТ + декор + тэглайн).
- Текст-якорь (slogan) — Space Grotesk uppercase tracked.
- Никаких фото на обложках кроме официального бренд-логотипа.

**Highlights / выделения** (вертикальные миниатюры):
- Фон Noir.
- В центре — иконка (минимальный sans-serif символ или короткое слово в Tenor Sans).
- Линия Dusty Rose под/над иконкой.

## Welcome-пост «Мы обновились» — один текст для всех

Адаптируется под платформу по длине. Базовая версия (IG / VK):

```
Мы обновились.

Студия декора, которую вы знали как «Декор свадеб СПБ» / Kit Wedding / WOW Decor — теперь это КИТ. Одно имя на всех площадках, один визуальный язык, та же команда из двух человек: Ольга и Андрей.

Что изменилось:
— название, единое везде: КИТ · декор на мероприятия
— визуальная подача: чёрно-белая редакторская эстетика, чтобы декор оставался главным героем
— подход к контенту: больше реальных кейсов, больше закулисья, больше живых историй

Что не изменилось:
— мы всё те же. Ольга и Андрей. 5 лет. 150+ событий. Каждый проект — наш с первого касания.
— цены, география, спектр работ — те же.

Спасибо, что вы с нами 🤍
```
