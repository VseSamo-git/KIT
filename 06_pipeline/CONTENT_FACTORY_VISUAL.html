01 — Главный принцип

Оля не пишет.
Оля решает.

Если Оля начала писать тексты руками — фабрика сломалась. Её роль: голос (через voice samples), идеи (через Idea Inbox) и финальное «да/нет» (через Approval view). Всё остальное делают агенты и n8n. Утром 15 минут — план дня закрыт.

«Я закидываю идею голосом, к обеду у меня 7 черновиков на все площадки — я выбираю.»
Так выглядит рабочий день Оли в новой системе. Не «садится писать пост», а «фильтрует то, что машина сделала за неё».

Что делает Оля

Закидывает идеи (голос/текст/фото). Утверждает черновики в Inbox. Отвечает на «горячие» лиды. Раз в неделю проверяет план. Раз в квартал — стратегическое ревю.

Что делает машина

Разворачивает идеи в 7 типов контента. Следит за трендами. Генерирует тексты в её голосе. Создаёт визуал (Kie.ai + Noir-шаблоны). Публикует в нужный час. Считает метрики и отвечает в DM.

02 — Карта агентов

12 агентов.
5 слоёв.

Каждый агент — отдельный n8n workflow или Claude-промпт. Цветная полоска сверху — слой ответственности: стратегия / планирование / производство / дистрибуция / обратная связь.

A01 · Стратегия
Brand Strategist
Раз в квартал. Читает все 12 стратегических доков + метрики квартала + Trend Watcher digest. Возвращает quarterly_brief.md: фокусы, риски, корректировки messaging.
Квартально · Claude API с кэшем 12 доков · альтернатива — CrewAI marketing-crew
A02 · Стратегия
Trend Watcher
Ежедневно. Парсит IG/TikTok/Pinterest по тегам декора и свадеб, считает audio-тренды Reels, формирует weekly digest. Питает Idea Expander и Editor свежими паттернами рынка.
Ежедневно 07:00 · n8n + Apify / Tavily / Pinterest API
A03 · Планирование
Editor-in-Chief
Каждое воскресенье 20:00. Балансирует пиллары (кейс / процесс / обучение / соцдоказ / продажи), вставляет тренды недели, ставит карточки в content_calendar со статусом «brief». Шлёт Оле в TG ссылку на план.
Вс 20:00 · n8n cron + Claude
A04 · Планирование
Idea Expander
Триггер: Оля закинула идею в Idea Inbox (текст, голос или фото). Агент развёртывает одну идею в 5–7 черновиков под все форматы: IG-пост, Reels, Stories-серия, TG, VK, Дзен, карусель.
По триггеру · мгновенно (≤2 мин)
A05 · Производство
Copywriter
Триггер: карточка со статусом «brief». Контекст в системном промпте: 04_BRAND_BOOK + 05_TOV + voice_samples + антимессенджи. Возвращает 3 варианта текста + 2 CTA + хэштеги.
По карточке · Claude Sonnet с prompt caching
A06 · Производство
Visual Director
Для Reels — пишет brief в Kie.ai (длительность, муз. вайб, монтажный стиль). Для Noir-карточек (цитата/цифра/типо-пост) — рендерит из HTML-шаблонов через Puppeteer в PNG.
По карточке · Claude + Kie.ai + Puppeteer node
A07 · Производство
Brand Guard
Проверка драфта: запрещённые слова из TOV («уникальный», «команда профессионалов»), упоминания старого бренда (Kit Wedding, WOW, Ivory/Sage), длина под платформу, наличие живой детали (имя/время/место).
Перед approval · Claude Haiku · быстрая проверка
A08 · Дистрибуция
Publisher
Cron каждый час. Берёт approved-карточки с publish_date≤now, постит через нативные API: IG Graph, VK group, TG Bot, Дзен. Меняет статус → published, сохраняет external_id.
Каждый час · n8n cron · IG/VK/TG/Дзен API
A09 · Дистрибуция
Repurpose
После публикации Reels — автоматически собирает TG-пост со ссылкой, VK-пост с видео, черновик Дзен-длиннюка. Один Reels превращается в 4 единицы контента.
После Publisher · n8n chain
A10 · Обратная связь
Analytics
Каждое утро 09:00. Тянет статистику постов (охват, сохранения, DM), пишет в таблицу metrics. Воскресенье — weekly recap Оле в TG: что зашло, что нет, какой пиллар недоосвоен.
Ежедневно 09:00 · n8n + IG/VK/TG insights API
A11 · Обратная связь
Inbox Bot
Триггер: DM или комментарий с маркером «сколько», «есть даты», «расскажите про услуги». Шлёт первый шаблонный ответ, создаёт лид в leads, пушит Олю в TG с кнопками «звонок / отложить / закрыть».
Realtime webhook · IG/TG/VK
A12 · Обратная связь
Case Reaper
Триггер: Оля поставила event.status=done и залила фото. Reaper выбирает лучшие 5–7 кадров по правилам брендбука и автоматически создаёт 5 готовых карточек: IG-кейс, Reels, TG-пост, VK, Дзен.
После события · n8n + Claude vision
03 — Пайплайн от идеи к лиду

Семь шагов.
48 часов цикл.

От момента, когда Оля закидывает идею голосом в TG-бот, до публикации поста проходит максимум 48 часов. Чаще — 4–6 часов, потому что машина ждёт только Олю.

01
Idea Inbox · Оля · Trend Watcher · Case Reaper

Идея попадает в систему

Три источника: голосовое от Оли через TG-бот → транскрибируется → запись в ideas. Trend Watcher предлагает свежий тренд недели. Case Reaper создаёт идеи автоматически после событий. Все — в одну таблицу.

02
Idea Expander · агент A04

Развёртка в 5–7 черновиков

Идея «клиенты подарили нам торт» → 5 карточек: IG-пост (фото+история), Reels (15 сек реакция), Stories (3 кадра), TG (короткий), Дзен (если есть смысл). Все в content_calendar со статусом brief.

03
Copywriter · Visual Director · Brand Guard

Параллельное производство

Каждая карточка идёт в трёх потоках: текст (3 версии), визуал (Kie.ai или Noir-шаблон), проверка Brand Guard. Статус → draft_ready. Оля получает уведомление в TG: «9 черновиков ждут».

04
Оля · NocoDB Inbox view

Одобрение или правка

Inbox view: только карточки draft_ready. Три кнопки на карточке: ✓ Approve / ↻ Revise (комментарий → Copywriter перегенерирует) / ✕ Reject. 80% случаев — Approve. 5 секунд на карточку.

05
Publisher · n8n cron

Автопостинг в нужный час

Карточка approved + publish_date достигнут → пост идёт в свою платформу через нативный API. Запись о external_id фиксируется. Ошибка → пуш Андрею в TG.

06
Repurpose · Analytics

Размножение и замер

После публикации Reels — Repurpose создаёт TG/VK/Дзен версии. Через 24 часа Analytics тянет первичные метрики (охват/сохранения), привязывает к карточке.

07
Inbox Bot · CRM

Лид падает в воронку

Пост вызвал DM → Inbox Bot отвечает шаблоном, создаёт leads.row, пушит Олю. Оля видит лид с контекстом: какой пост его привёл, что человек спросил. Конверсия становится attributable.

04 — Idea Expander · детально

Одна идея Оли →
7 форматов контента.

Это сердце системы. Оля больше не думает «надо что-то выложить в IG, отдельно в TG». Она думает «у нас была такая история». Машина сама раскладывает на форматы.

Что Оля делает

Открывает TG-бот @kit_ideas. Жмёт микрофон. Говорит 20 секунд. Может приложить фото. Бот отвечает: «принято, через 3 минуты придут 6 черновиков на ревью».

Что машина делает

Whisper транскрибирует голос. Idea Expander анализирует: эмоция, тип события, есть ли визуал, какой пиллар. Решает, какие из 7 форматов уместны (не всегда все). Создаёт N карточек, дальше — обычный пайплайн.

05 — Трендвотчинг

Мы не отстаём
от рынка.

Trend Watcher работает каждое утро в 07:00. Тянет данные из четырёх источников, сравнивает с прошлой неделей, выводит digest. Editor использует его при планировании, Idea Expander — чтобы «приземлить» идею Оли в актуальный формат.

Источник 01 · Instagram
Растущие хэштеги по СПб-свадьбам, аудио-треки Reels с ускоренным охватом, форматы карусели
Apify scraper по списку конкурентов и тегам #свадьбаспб #декорспб
Источник 02 · Pinterest
Палитры сезона, флористические композиции, новые ритуальные элементы (smoke-box, парковка каблуков)
Pinterest Trends API + ручные board-listy от Оли
Источник 03 · TikTok
Вирусные ракурсы съёмки декора, тайм-лапс-форматы, повторяющиеся «hook»-фразы для подписей
Apify TikTok-scraper + теги #weddingdecor #floraldesign
Источник 04 · Свадебные медиа
Gorko, The Knot RU, свадебные блоги — крупные публикации, тренды сезона, новые имена декораторов
RSS + Tavily Search еженедельно
Источник 05 · Конкуренты
Что выкладывают @feerichi, @thefair.ru, Oh My Flowers, ТоржествоМания — частота, форматы, что зашло
IG scraper по списку, ручной alert при необычной активности
Источник 06 · Своё прошлое
Метрики наших же постов: какие форматы у нас работают, какие пиллары перегружены, когда лучшее время выхода
Внутренняя metrics-таблица NocoDB
Trend Watcher не диктует — он доказывает.
Каждый alert приходит Оле с доказательством трендовости: 3+ скриншота от топ-аккаунтов за 7 дней, цифры роста хэштега, ссылки на конкурентов, использовавших элемент. Оля видит «кто в топе тренда» и решает — наше или нет. Никаких автоматических вставок «при score≥8». Финал всегда за ней. Каноническая логика — в 06_pipeline/CONTENT_LOGIC.md.

09 — Технологический стек

Четыре инструмента.
Всё.

Никаких лишних SaaS. Каждый компонент несёт свою функцию, нет дублей.

01
Claude API
Мозг агентов
Sonnet для текстов и анализа, Haiku для быстрых проверок. Prompt caching на системных промптах с брендбуком и voice_samples — экономия 70% токенов.
02
Kie.ai
Видео и Reels
Генерация Reels-роликов из текстового brief. Альтернатива — Pika / Runway, если Kie.ai не справится с эстетикой Noir.
03
NocoDB
База + интерфейс Оли
Self-hosted на VPS. Таблицы, формы, calendar view, кнопки с webhook. Оля видит интерфейс уровня Airtable, бесплатно.
04
n8n
Оркестратор
Self-hosted рядом с NocoDB. Все агенты — это n8n workflow с триггерами: cron, webhook, NocoDB change. Каждый агент = один workflow.
